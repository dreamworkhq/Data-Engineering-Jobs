Once a day. A GitHub Action pulls new data engineering listings from Dreamwork's public API, which crawls company career pages directly (Greenhouse, Lever, Ashby, Workday, and others). Use <kbd>Ctrl</kbd>+<kbd>F</kbd> for Spark, dbt, Airflow, Snowflake, or warehouse roles.

<details>
<summary><strong>What counts as a data engineering job here?</strong></summary>

Roles whose title names data engineering work: data engineer, analytics engineer, data platform, data infrastructure, ETL, or data warehouse. Data scientist and analyst roles have <a href="https://github.com/dreamworkhq/Data-Science-Jobs">their own list</a>.

</details>

<details>
<summary><strong>Where does the salary data come from?</strong></summary>

From the postings themselves. When a posting does not state pay, the column is blank. Nothing is estimated.

</details>

</details>

## How this list is built

A [GitHub Action](.github/workflows/update.yml) runs once a day. It queries Dreamwork's public listings API, filters for data engineering roles (pipelines, warehouses, analytics engineering, data platform), removes duplicates, and rewrites this README. The raw snapshot lives in [`data/listings.json`](data/listings.json). Listings are crawled directly from company career pages and ATS boards (Greenhouse, Lever, Ashby, Workday, and others), so links go to real, currently open postings. Found a bad listing? [Open an issue](../../issues).
